## WTFPLを利用するにはどうすればよいでしょうか?

*ステップ1* あなたの製作物に WTFPL の [全文](https://www.wtfpl.net/txt/copying) をダウンロード、もしくはペーストして添付し、頒布します。
ライセンスファイルの一般的なファイル名は `COPYING` です。
もし複数のライセンスを引用するなら、WTFPLのライセンスファイル名は `COPYING.WTFPL` とするのが妥当でしょう。

*ステップ2* あなたの制作物に以下の文言を付与します。

```
Copyright © 2000 Your Name <your@address>
This work is free. You can redistribute it and/or modify it under the
terms of the Do What The Fuck You Want To Public License, Version 2,
as published by Sam Hocevar. See the COPYING file for more details.
```

もし現実的な問題として制作物に `COPYING` ファイルを別添できないのであれば、
以下に示すライセンスを制作物にペーストすることもできます。
もしくは、このサイトへリンクすることでライセンスの内容を示すこともできます。

```
Copyright © 2000 Your Name <your@address>
This work is free. You can redistribute it and/or modify it under the
terms of the Do What The Fuck You Want To Public License, Version 2,
as published by Sam Hocevar. See http://www.wtfpl.net/ for more details.
```

## もしプログラム名を変更できない場合においても、無制限（フリー）なライセンスと言えますか?

あなたはソフトウェアの名前を変えることが可能です。前章をもう一度読んでください

## WTFPLは正当な（有効な）ライセンスですか?

WTFPL の正当性が裁判所で検証されたことはありませんが、有効なライセンスとして広く受け入れられています。

主なLinuxディストリビューション (Debian, Fedora, Arch, Gentoo, etc) は WTFPL version 1 もしくは 2 で
ライセンスされたソフトウェアを同梱しています。Bradly Kuhn（フリーソフトウェア財団事務局長）は、
FSFメンバーが WTFPL は正当なフリーソフトウェア・ライセンスであると同意していることを [示して](http://lists.debian.org/debian-legal/2002/09/msg00032.html) います。

## なぜ無保証条項がないのですか?

WTFPL はコンピュータ・プログラムに限らず、アートワークや文章などにも利用できる汎用ライセンスです。
そのため WTFPL はコピー・頒布・改変のみをカバーしています。
もしプログラムに無保証条項を追加したい場合は、以下の文言をソースコードに付与することができます。

```
/* This program is free software. It comes without any warranty, to
     * the extent permitted by applicable law. You can redistribute it
     * and/or modify it under the terms of the Do What The Fuck You Want
     * To Public License, Version 2, as published by Sam Hocevar. See
     * http://www.wtfpl.net/ for more details. */
```

## このライセンスは本質的にパブリック・ドメインと同じではありませんか?

残念ながらパブリック・ドメインの定義は管轄区域によって異なり、
いくつかの地域においては、過去70年間において存命であった者の制作物をパブリック・ドメインとするかに議論の余地があります。

## ライセンスの言葉遣いを変えられないのですか? 不適切で、幼稚で、企業倫理に反しています

WTFPLの下において、あなたは制作物を他のライセンスで再ライセンスすることができます。

## 下品だって分からないのか?

お前の「下品」に対するスタンスなど知ったことじゃない。お前の中の優先順位など知ったことではない。
WTFPLが掲げているのは *Fucking Freedom* （クッソ自由）ということだ。
自由という言葉が意味するものは、何も芸術や科学的成果を人類で分かち合ったり、コピーしたり、弄るような自由だけじゃない。
同性愛者になって結婚して狂ったゲイセックスをする自由、
体に刺青を入れる自由、神など存在しないと宣言する自由、
避妊薬を飲む自由、中絶を行う自由、それらすべてが「自由という言葉」に含まれている。
**人間は同性愛者や無神論者だったせいで死ぬんだぞ?**
"Fuck" を見たせいで穢れるほど神聖なものがある、などと言ってくれるんじゃない。
もしお前が WTFPL の F (Fuck) は攻撃的だ、などと宣うのならお前のその信念も大概カスだ。
Triple Fuck You.
