# WTFPL Frequently Asked Questions (ja_jp)

これは [WTFPL – Do What the Fuck You Want to Public License のFAQページ](https://www.wtfpl.net/faq/) の内容の一部を日本語に意訳したものである。

* このコンテンツは 2026-09-11 時点でのWebサイトの記述内容に基づく

## WTFPLを利用するにはどうすればよいでしょうか?

**ステップ1** あなたの著作物に WTFPL の [全文](https://www.wtfpl.net/txt/copying) をダウンロード、もしくはペーストして添付し、頒布します。

ライセンスファイルの一般的なファイル名は `COPYING` です。
もし複数のライセンスを引用するなら、WTFPLのライセンスファイル名は `COPYING.WTFPL` とするのが妥当でしょう。

**ステップ2** あなたの著作物に以下の文言を付与します。

```
Copyright © 2000 Your Name <your@address>
This work is free. You can redistribute it and/or modify it under the
terms of the Do What The Fuck You Want To Public License, Version 2,
as published by Sam Hocevar. See the COPYING file for more details.
```

もし現実的な問題として著作物に `COPYING` ファイルを別添できないのであれば、
以下に示すライセンスを著作物にペーストすることもできます。
もしくは、このサイトへリンクすることでライセンスの内容を示すこともできます。

```
Copyright © 2000 Your Name <your@address>
This work is free. You can redistribute it and/or modify it under the
terms of the Do What The Fuck You Want To Public License, Version 2,
as published by Sam Hocevar. See http://www.wtfpl.net/ for more details.
```

## もしプログラム名を変更できない場合においても、無制限（フリー）なライセンスと言えますか?

WTFPLではソフトウェア名を変えることも許されます。前章をもう一度読んでください。

## WTFPLは正当な（有効な）ライセンスですか?

WTFPL の正当性が裁判所で検証されたことはありませんが、有効なライセンスとして広く受け入れられています。

主なLinuxディストリビューション (Debian, Fedora, Arch, Gentoo, etc) は、 WTFPL version 1 もしくは 2 で
ライセンスされたソフトウェアを同梱しています。Bradley Kuhn フリーソフトウェア財団事務局長は、
FSFメンバーが「WTFPL は正当なフリーソフトウェア・ライセンスであると同意している」ことを [示して](http://lists.debian.org/debian-legal/2002/09/msg00032.html) います。

## なぜ無保証条項がないのですか?

WTFPL はコンピュータ・プログラムに限らず、アートワークや文章などにも利用できる汎用ライセンスです。
そのため WTFPL はコピー・頒布・改変のみをカバーしています。

もしプログラムに無保証条項を追加したい場合は、以下の文言をソースコードに付与することができます。

```
/* This program is free software. It comes without any warranty, to
 * the extent permitted by applicable law. You can redistribute it
 * and/or modify it under the terms of the Do What The Fuck You Want
 * To Public License, Version 2, as published by Sam Hocevar. See
 * http://www.wtfpl.net/ for more details. */
```

## このライセンスは本質的にパブリック・ドメインと同じではありませんか?

残念ながらパブリック・ドメインの定義は管轄区域によって異なります。
いくつかの地域においては、死語70年を経過していない者の著作物をパブリック・ドメインとするかは議論の余地があります。

## ライセンスの汚い言葉遣いを直せませんか? 不適切で、幼稚で、企業に相応しくない

WTFPLの下において、あなたは著作物を他のライセンスで再ライセンスすることができます。

## だから下品だっつってんのが分からないか?

お前の「下品」に対するスタンスなど知ったことじゃない。お前の人生の価値観なんて知ったことではない。

WTFPLとは fucking freedom ——ファッキンなほどの『自由』を意図したライセンスだ。本気でそう思って名付けたんだ。

自由という言葉は、何も芸術や科学的成果を人類で分かち合ったり、コピーしたり、改変するような行為だけを示すものじゃない。
同性愛者になる自由、結婚して滅茶苦茶なゲイセックスをする自由、体に刺青を彫り込む自由、神など存在しないと宣言する自由、避妊薬を飲む自由、中絶を行う自由、それらすべてが「自由」という言葉に含まれている。

**人間は同性愛者や無神論者だったせいで死ぬんだぞ。**

Fuckという言葉から護るべき神聖なものがあるなんて言ってくれるな。もしお前が WTFPL の `Fuck` が不快だの下品だの宣おうなら、お前も、そんなお前の信念も、すべてFuckだ。

Triple Fuck You.
